  POMA 프로젝트 완성

  파일 구조 (10개 Swift 파일)

  ┌─────────────────────────────┬─────────────────────────────────────────────────────────┐
  │            파일             │                          역할                           │
  ├─────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ POMAApp.swift               │ 앱 진입점, SwiftData 컨테이너 설정                      │
  ├─────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ ContentView.swift           │ 3개 탭 (지출 / 현금입력 / 설정)                         │
  ├─────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ Transaction.swift           │ SwiftData 모델 - 거래 내역                              │
  ├─────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ SpendingCategory.swift      │ 16개 카테고리 enum + 아이콘/색상                        │
  ├─────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ ExcelImporter.swift         │ CoreXLSX로 뱅크샐러드 xlsx 파싱                         │
  ├─────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ MonthlySpendingView.swift   │ 월별 지출 메인화면 (월선택, 요약, 도넛차트, 카테고리별) │
  ├─────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ CategoryBreakdownView.swift │ 카테고리 파이차트                                       │
  ├─────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ TransactionListView.swift   │ 날짜별 개별 거래 리스트                                 │
  ├─────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ AddCashView.swift           │ 현금 지출 입력 폼                                       │
  ├─────────────────────────────┼─────────────────────────────────────────────────────────┤
  │ SettingsView.swift          │ 엑셀 임포트, 데이터 삭제, 현황                          │
  └─────────────────────────────┴─────────────────────────────────────────────────────────┘

  사용 흐름

  1. 설정 탭 → "엑셀 파일 가져오기" → 뱅크샐러드 xlsx 선택 → 지출 내역 자동 임포트
  2. 지출 탭 → 좌우 화살표로 월 이동 → 카테고리별 비율/금액 확인 → 카테고리 탭하면 해당 내역만 필터
  3. 현금 입력 탭 → 날짜/카테고리/내용/금액 입력 → 저장 (지출 탭에서 "현금" 배지로 구분)

  실행 방법

  Xcode를 설치한 뒤 POMA/POMA.xcodeproj를 열면 자동으로 CoreXLSX 패키지를 다운로드하고 빌드할 수 있습니다. iOS 17+
  시뮬레이터 또는 실기기에서 실행하면 됩니다.
